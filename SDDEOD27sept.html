Metrics Logic:

Report Window = Creation Date after (D-1) <brand's cutoff hour> and up to and including (D) <brand's cutoff hour>. Each brand's cutoff hour comes from Column B of the Brand Sheet — see the window note above, or each report's header below, for the exact time used.
Darkstore Columns (brand-wise reports) = every darkstore in the file appears. Darkstores listed in the Darkstore Sheet are renamed to their Name, and darkstores sharing a Name are combined into one column. Darkstores not in the sheet keep their usual label.
Darkstore-Wise Report = only darkstores listed in the DS EOD tab appear, renamed to their Name; darkstores sharing a Name are merged into one row. Rows follow the order of the DS EOD tab. Uses a fixed 4:00 PM → 4:00 PM window for every brand.
Test Orders = any row whose Darkstore or Brand Name starts or ends with "test" (any case) is removed from every report.
Excluded Pincodes = every pincode in the Pincode Sheet is removed from both uploads — Delivery Pincode in the shipment file and Shipping Address Pincode in the Kapiva order files — before any count.
Total Orders = Count of all rows/orders in the window
Kapiva Total Orders = from the Kapiva order files: Created after (D-1) 4:00 PM and up to and including (D) 4:00 PM, excluding CANCELLED in Sale Order Status or Sale Order Item Status, counted as unique Display Order Codes per Facility. If a store's Total Orders is lower than its Processed count, Total Orders is raised to Processed.
Not_D0_Dispatched Orders = Current Status = READY
D0_Dispatched Orders = Total Orders - (READY Orders with 0 attempt)
Cancelled Orders = Current Status = CANCELLED
FASR% = (Delivered Orders / Processed Orders) × 100
