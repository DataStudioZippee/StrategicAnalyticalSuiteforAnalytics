Works with the Odoo “Quants (stock.quant)” export in .xlsx or .csv. The file stays in your browser; nothing is uploaded to a server.

How the dashboard reads the file

It needs Location, Product and Inventoried Quantity; Unit, Reserved Quantity and Lot/Serial Number are used when present. Stock sitting directly at the main location (WH/Stock) counts as pending putaway; stock in its sub-locations (the rack bins) counts as already put away. Subtotal rows like “WH/Stock (168)” are skipped.
