Metrics Logic:

Report Window = Creation Date after (D-1) <brand's cutoff hour> and up to and including (D) <brand's cutoff hour>. Each brand's cutoff hour comes from Column B of the Brand Sheet — see the window note above, or each report's header below, for the exact time used.
Total Orders = Count of all rows/orders in the window
Not_D0_Dispatched Orders = Current Status = READY
D0_Dispatched Orders = Total Orders - (READY Orders with 0 attempt)
Cancelled Orders = Current Status = CANCELLED
FASR = (DELIVERED Orders having Attempt = 0 / Total Orders) × 100
