2. Report Logic
Fixed pipeline (applied in order):
  1. Keep only MP Name = Shopify rows.
  2. Check that subset's Order Status for Pending — if found, a caution popup appears and those rows are excluded from the report below.
  3. Add a helper Unique Column on Reference Code (column E): the first row seen for each Reference Code is Unique, every repeat is Duplicate — same as =IF(COUNTIF($E$2:E2,E2)=1,"Unique","Duplicate"). This collapses a multi-product order (several suborder rows, one shared shipment) down to one counted row.
  4. Pivot, filtered to Unique Column = Unique and the selected couriers below — Rows: Import Date (by day) · Columns: Shipping Status · Values: count of AWB No — one table per selected courier.
